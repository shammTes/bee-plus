# Bee Plus

Junior (Grade 6–8) offline study app. Sister of **4** (high school).

- Locked on first install.
- Unlock with Bee Seller (package code `JUNIOR`, same HMAC as 4).
- After unlock, opens the Junior clay UI (Tigrinya + English) full screen.

## Build

GitHub Actions builds `bee-plus-student.apk` on every push to `main`.
